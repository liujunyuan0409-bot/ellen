# Changelog

## 0.2.0 — 2026-11-16

**Windows 版未经真机验证**：Windows 部分只在 macOS 上用单元测试验证过，验收清单见 [WINDOWS_CHECKLIST.md](WINDOWS_CHECKLIST.md)。

### 每周备份
- 备份频率从「每 24 小时」改为**每周一次，默认每周一 12:00**（本机时区），可用 `setup --schedule --weekday N --time HH:MM` 修改；定时任务每小时检查一次、登录时也检查一次，上一个计划时间点之后还没成功才真正备份，错过了开机/唤醒后补跑。
- 没读全的那次（不算成功）之后 6 小时内不再重试，避免某个文件夹一直读不了时每小时扫一遍；登录过期、磁盘满、离线的中止不受这个限制。
- 「很久没备份成功」的提醒改为：上次成功早于往前数第二个计划时间点（连续错过两周），每天最多提醒一次。
- 没到备份时间时，登录信息超过一天没续期就顺手续期一次（飞书的续期凭据只管 7 天，否则每周都可能要重新登录）。
- 顺手续期登录时只试一次（15 秒超时、不退避），不再因为续期重试把「立即备份」挡上几分钟；续期被拒时只有飞书明确说「续期凭据失效 / 过期 / 被吊销 / 已用过」（错误码 20026、20037、20064、20073、20074 或 `invalid_grant`）才提示重新登录，其他错误码当作暂时故障、下个小时再试（正常备份时的续期同样处理）。
- 证书校验失败不再当成「离线」静默跳过：弹一次通知（每天最多一次）给出按系统的修法，记一次不成功，退出码 1；下个小时照常再试。
- 「很久没备份成功」的提醒也覆盖从没成功过的情况：以第一次尝试的时间为起点，一次都没尝试过就以第一次 `setup --schedule` 的时间为起点（记在配置的 `schedule_installed_at`）。
- `setup --schedule` 先用定时任务将要用的那个 Python 试连一次飞书（20 秒超时）：证书校验失败或连不上就不安装，显示 ✗ 和修法。
- `status` 显示「下次计划：每周一 12:00（日期 时间）」。

### Windows 支持
- 新增 `fbk/platform/`，按系统选实现：配置 / 日志 / 程序副本位置（`%APPDATA%`、`%LOCALAPPDATA%`）、任务计划程序（`schtasks /Create /XML`，登录时 + 每小时，仅在用户登录时运行，用 `pythonw.exe` 不弹黑窗口）、PowerShell 通知、tkinter 置顶输入窗口（不可用时回退 PowerShell `Read-Host`）、`msvcrt` 运行锁、`SetThreadExecutionState` 防睡眠。
- 所有文件操作在 Windows 上走 `\\?\` 长路径；清单里绝不保存带前缀的路径。
- 中文 Windows 上输出被 AI 工具接走时改用 UTF-8，打印 ✓ 不再报错。
- 证书校验失败时的修法按 Python 的来源给：python.org 装的给对应版本的 `Install Certificates.command`，macOS 自带的（`/usr/bin/python3`、命令行工具）让更新 macOS 或改装 python.org 的 Python，Homebrew 装的给 `brew reinstall ca-certificates openssl`，认不出来时三种都列上。
- 向导新增：证书检查、OneDrive 同步目录提醒、备份目录路径过长提醒；Python 版本过低、目录无权限的修法按系统给出。
- Windows 上 `doctor` / `status` 第一行标注「Windows 版未经真机验证」，`--json` 带 `windows_unverified: true`。

### 文件名（两系统统一）
- `/ \ : * ? " < > |` 和控制字符换成 `_`；去掉结尾的空格和点；Windows 保留名（`CON` `PRN` `AUX` `NUL` `COM1–9` `LPT1–9`，不区分大小写、带扩展名也算）加前缀 `_`；单个名字不超过 255 字节。
- 同目录同名判断改为不区分大小写，重名的加 ` (token 前 6 位)`；自己的文件按同一文件判断（不受大小写 / Unicode 组合形式影响），符号链接一律算占用。
- 从 v0.1.0 升级后第一次运行，名字按新规则变了的文件会在本地改名（移动），不会重新下载。
- 下载临时文件名改用完整 token 的哈希，避免两个 token 前缀相同时串用。

### 任意 AI 助手都能安装
- 新增仓库根目录 `AGENTS.md` 和插件目录 `AGENTS.md`（唯一的操作说明）：准备（检查 / 安装 Python、取得程序、`install`）、7 步向导、写给 AI 的注意事项（沙箱与联网、后台运行、弹窗等待、绝不经手 App Secret）、日常操作、退出码排障。`SKILL.md` 只保留触发词并指向它。
- 新增 `install` 命令：把程序复制到本机固定位置，不装定时任务。
- 程序里给用户的提示不再写死「对 Claude 说」，改为「对你的 AI 助手说」。

### v0.1.0 遗留问题
- 程序副本按版本分目录存放（`app/versions/<版本>/` + `current` 指针 + 启动器 `launch.py`）：更新副本时不再有目录短暂不存在的瞬间；正在运行的旧版本目录不会被删，没人用了才清理；v0.1.0 的旧布局挪到 `app.legacy-<时间>/`，不删除。
- 通过启动器运行 `setup --schedule`（改备份时间、首次备份还在跑时重装）时，复制源就是正在运行的副本：不再复制和换目录，只改写 `current` 和启动器——Windows 上不再报「程序副本正被运行中的备份占用」，Mac 上不再多留一个 `.old-*` 目录；目标已是一模一样的同版本副本时也不换。
- 同版本重装时挪到旁边的旧副本改名为 `.<版本>.old-<时间>-<PID>`；同名的旧旁置目录要确认没人在用（拿到 `in_use` 锁）才清掉，有人在用就换个名字，不会误删正在运行的副本。
- 迁移旧清单按记录下来的旧备份根目录截取路径（旧目录名里恰好含「我的空间」等字样时不再截错）；没有记录时依次尝试各个截断点，都找不到就按第一个顶层目录截取（同 v0.1.0）。

### 其他修复
- 同一分钟内跑两次时，第二份备份日志不再覆盖第一份（改名为 `…_HHMM（2）_备份日志.md`）。
- 重新填写凭证不再把计划时间重置为默认值；计划时间写错时加载即报错，`status` 照常显示其余信息。

### 终审修复
- `setup --status` 的第 7 步：定时任务装了但跑不了时显示 ✗ 和原因，不再显示 ✓。
- `schedule uninstall` 删不掉定时任务时（如 Windows 上拒绝访问）给中文的 ✗ 和手动删除的步骤，退出码 1，不再抛英文异常。

### 文档
- README 改写：macOS + Windows、每周一次与「历史版本是每周快照」、授权是累计的（如何撤销后重新登录得到真正只读的登录）、多人 / 多台电脑各自登录、登录有效期、两个系统分别的卸载步骤。
- 新增 `WINDOWS_CHECKLIST.md`：Windows 真机逐条验收清单。

## 0.1.0 — 2026-11-14

- 首个版本：备份我的空间、知识库、共享给我、群聊附件（文件与音视频）到本地 Mac。
- 在线文档导出 PDF，表格 / 多维表格导出 xlsx，上传文件与附件保留原格式；思维笔记等无导出接口的类型跳过并记录。
- 增量备份与断点续跑；云端改过的文件旧版移入 `历史版本/` 按日期命名，从不删除或覆盖本地文件；同一文件只存一份。
- 群聊链接扫描与权限缺口报告（CSV）；每次运行生成备份日志。
- 7 步配置向导（凭证走系统弹窗，5 分钟无操作自动取消）、8 项权限体检、只统计不下载的首次扫描。
- 系统定时任务：每小时检查、满 24 小时才备份，Mac 开机后自动补跑；出错、需要重新登录、备份盘没插或空间不足时弹系统通知。
- HTTP 客户端只读白名单，限流与重试。只用 Python 标准库。
- 清单存相对备份根目录的路径：整个备份目录复制或搬到别处后直接续上，不会重新下载、也不会搬动旧副本。
- 运行锁用 flock，关机或被杀后不会留下挡住备份的锁；定时任务收到 SIGTERM 时正常收尾。
- 定时任务运行 `~/Library/Application Support/feishu-backup/app/` 里的程序副本（优先系统 python3，带 caffeinate 防空闲睡眠）；插件更新后重新运行 `setup --schedule`，`status` / `doctor` 会提示。
- 中途断网或飞书 5xx 按离线处理，不记为成功；令牌被吊销直接提示重新登录。
- 配置或登录文件损坏、备份目录没有访问权限、超过 3 个备份周期没成功，都会弹系统通知。
- 备份日志按 `YYYY-MM-DD_HHMM` 命名，同一天多次运行各留一份。
- 登录只申请 24 项实际用到的只读权限。
